TO RUN ON YOUR WINDOWS PC
================================================================================

METHOD 1: Run from Source (Recommended for testing)
----------------------------------------------------
1. Open Command Prompt or PowerShell

2. Navigate to project folder:
   cd C:\path\to\ssh-tunnel-manager

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python src\main.py

5. (Optional) Run tests:
   pip install pytest
   pytest tests\unit\ -v


METHOD 2: Build Standalone .exe
--------------------------------
1. Open Command Prompt or PowerShell

2. Install build dependencies:
   pip install -r requirements-dev.txt

3. Run build script:
   build.bat

4. Find executable:
   dist\SSH-Tunnel-Manager.exe

5. Double-click to run!

================================================================================
WHAT THE APPLICATION DOES
================================================================================

✨ Complete SSH Tunnel Management:
   • Connect to SSH servers (password or key authentication)
   • Create Local (-L), Remote (-R), and Dynamic (-D) tunnels
   • Save and load connection profiles
   • Monitor tunnel health and auto-reconnect
   • Export SSH commands and scripts

🔒 Security Features:
   • Passwords stored in Windows Credential Manager
   • Profiles encrypted with AES-256
   • Input validation to prevent attacks
   • No plain-text password storage

🎨 Modern GUI:
   • Dark and light themes
   • Real-time status indicators
   • Color-coded log console
   • Connection and tunnel management panels

================================================================================
QUICK USAGE EXAMPLE
================================================================================

1. Start the application:
   python src\main.py

2. Enter SSH connection details:
   - Host: your-server.com
   - Port: 22
   - Username: your-username
   - Auth: password
   - Password: your-password

3. Click "Connect"

4. Add a tunnel:
   - Type: Local
   - Local Port: 8080
   - Remote Host: localhost
   - Remote Port: 80

5. Click "Add Tunnel"

6. Access forwarded service:
   - Open browser: http://localhost:8080
